# Cahier d'exercices d'harmonie

Ce cahier accompagne le [Cours d'écriture et d'harmonie](../README.md) : il suit le cours chapitre par chapitre, avec beaucoup de **basses données** et de **chants donnés**. Chaque exercice a son corrigé (une solution parmi d'autres), gravé et à écouter.

Dans la version web (`cahier.html`), on fait les exercices **directement sur la portée** : on choisit une voix, on clique pour poser les notes, et les corrections s'affichent au fur et à mesure. Basses données et chants donnés se font par étapes (trouver les accords, écrire le soprano ou la basse, compléter l'alto et le ténor).
